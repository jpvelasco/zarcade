      ←→ choose · Enter play · 🎮 gamepads welcome · every game has a ← Arcade button to come back

      Opened from disk, so only games marked works offline can start. Run npm run serve and visit http://localhost:8000 to play them all.

      Help & diagnostics

      If a game misbehaves, its log below shows what happened. Copy the report and send it to whoever looks after the arcade. Logs stay on this device unless you switch on sending.

        Send logs (OpenTelemetry)

        The dev server (npm run serve) collects logs at /v1/logs into logs/telemetry.ndjson. Any OTLP/HTTP collector works too, such as http://localhost:4318.
